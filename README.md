# Birthday Telegram Bot

Telegram-бот хранит дни рождения, подписки и whitelist в PostgreSQL, присылает еженедельный дайджест по пятницам в 12:00 по Москве и отдельное уведомление в 08:00 в сам день рождения.

## Что умеет

- хранит данные в PostgreSQL;
- умеет один раз импортировать дни рождения из `.xlsx`, если таблица в БД еще пустая;
- отправляет рассылку по всем чатам, где был вызван `/start`;
- позволяет проверить текущее сообщение командой `/check`;
- показывает весь список дней рождений командой `/list`;
- добавляет запись командой `/add`;
- удаляет запись командой `/delete`;
- пускает в бота только пользователей из белого списка;
- позволяет управлять белым списком через команды `/add_whitelist` и `/del_whitelist`;
- показывает список команд в меню Telegram.

## Подготовка

1. Создайте бота через `@BotFather` и получите токен.
2. Создайте `.env`:

```bash
cp .env.example .env
```

3. Укажите `BOT_TOKEN`.
4. Укажите `INITIAL_WHITELIST_USER_IDS` через запятую. Это стартовые Telegram user ID, которым будет разрешен доступ в бот.
5. При необходимости укажите `BIRTHDAYS_FILE`. Если файл указан и таблица `birthdays` пуста, бот импортирует данные при старте.

## Запуск Через Docker

```bash
docker compose up --build -d
```

После запуска:

- откройте чат с ботом;
- отправьте `/start`, чтобы подписать этот чат;
- отправьте `/check`, чтобы увидеть сообщение, которое уйдет в ближайшую пятницу;
- отправьте `/list`, чтобы увидеть все дни рождения с ID;
- используйте `/add ФИО | Подразделение | ДД.ММ`, чтобы добавить запись;
- используйте `/delete ID`, чтобы удалить запись;
- `/stop` отключает подписку.

Полезные команды:

```bash
docker compose logs -f
docker compose restart
docker compose down
```

## Как Это Работает В Docker

- compose-проект явно называется `birthday_bot`, поэтому контейнеры и сеть поднимаются именно в этой группе;
- `docker-compose.yml` поднимает сервисы `birthday-bot` и `postgres`;
- PostgreSQL хранит дни рождения, подписки и whitelist;
- Excel-файл примонтирован в контейнер только на чтение и используется только для первичного импорта;
- если в `data/subscribers.json` или `data/whitelist.json` есть legacy-данные, бот переносит их в PostgreSQL при старте;
- еженедельная рассылка запускается по пятницам в `12:00` по `Europe/Moscow`;
- ежедневная рассылка с именинниками на сегодня запускается каждый день в `08:00` по `Europe/Moscow`;
- в рассылку попадают суббота и воскресенье текущей недели, а также вся следующая неделя с понедельника по воскресенье;
- если PostgreSQL уже содержит дни рождения, повторный импорт из Excel не запускается.

## Настройки

- `DATABASE_URL` - строка подключения к PostgreSQL;
- `TIMEZONE` - часовой пояс для расчета дат и времени запуска;
- `INITIAL_WHITELIST_USER_IDS` - стартовые Telegram user ID через запятую для первого запуска;
- `BIRTHDAYS_FILE` - путь к `.xlsx` для первичного импорта;
- `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` - параметры контейнера PostgreSQL в Docker Compose.

## Формат Excel

Бот читает первый лист файла. Даты надежнее всего брать из колонок `D` и `E`, поэтому при импорте сначала используются они, а затем запасной разбор текстовой даты из колонки `C`.

## Команды Изменения Списка

- `/list` - выводит весь список с ID записей;
- `/add Иван Иванов | Отдел продаж | 07.04` - добавляет новый день рождения;
- `/add Иван Иванов | 07.04` - добавляет запись без подразделения;
- `/delete 42` - удаляет запись по ID из вывода `/list`;
- `/add_whitelist 123456789` - добавляет пользователя в белый список;
- `/del_whitelist 123456789` - удаляет пользователя из белого списка.

## Авторизация

- любой пользователь вне белого списка получает `Ошибка авторизации`;
- в тексте ошибки бот показывает Telegram user ID, который нужно передать администратору;
- whitelist хранится в PostgreSQL;
- команды whitelist доступны только уже авторизованным пользователям;
- последнего пользователя из белого списка удалить нельзя, чтобы не заблокировать бота полностью.

## Логика Рассылки

- по пятницам в 12:00 по Москве бот отправляет один список;
- список покрывает даты с субботы сразу после этой пятницы и до воскресенья следующей недели включительно;
- поэтому суббота и воскресенье всегда попадут в две соседние пятничные рассылки.
- если в пятничном периоде нет дней рождений, приходит сообщение `Дней рождений в Сбере на следующей неделе нет.`
- каждый день в 08:00 по Москве, если есть именинники на сегодня, приходит сообщение в формате `День рождения сегодня - ДАТА у:`.
